Send these two values to the ESP32 through its setup hotspot. No code editing or re-flashing needed.

How to enter them on the ESP32
  1. Connect the ESP32 by USB, open the Arduino Serial Monitor (115200 baud), type setup in the message box and press Send. (Holding BOOT for 3 seconds also works, and a new or unconnected board opens the hotspot by itself.)
  2. On your phone, join Wi-Fi SmartFloodSetUp (default password smartflood123).
  3. The setup page opens by itself, or go to http://192.168.4.1.
  4. Paste the Server URL and API key above, choose your Wi-Fi, then tap Save & restart.

The server URL must use this PC's LAN IP (filled in for you), and the PC and ESP32 must be on the same Wi-Fi. For PythonAnywhere, use your https://yourname.pythonanywhere.com/api/sensor-data/ address instead.
